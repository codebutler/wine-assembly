## What the patch does / does not do

Microsoft's archived input/output capability references specify a bounded
copy and success without writes for a zero length. Previously output wrote
the full structure even for cb=0; input rejected all short buffers. Both
assumed affine backing. The shared writer bounds each byte to
min(cb,sizeof), uses one guest span, supports partial UTF-16 fields, preserves
excess caller bytes, and releases scratch after writeback. NULL/nonzero uses11.

Names, PCM formats and capabilities are unchanged. Device selection is still
incomplete: capture accepts only ID0, output ignores the selector; mapper and
live-handle semantics remain to implement. W entry points are compatibility
extensions, not proven native Win98 Unicode behavior. No benchmark or browser
gameplay claim applies to this patch.
