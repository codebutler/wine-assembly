## Cross-cutting gaps and invariants

1. **Contract coverage is partial.** Existing neutral opcode names are not proof of execution support. M:`d3d9-software-backend.js:1065` has no COPY/BIND case; unsupported commands fail. D3D9 Lock/GetDC/GetRenderTargetData/StretchRect-related CPU access is coordinated through explicit READBACK in `d3d9-host.js:745`, not a proven universal native COPY command. Do not generalize Pirates' unexercised StretchRect route into accepted copy coverage.
2. **Semantic duplication remains at different layers.** Main GPU fixed-function JS and software native fixed compiler are separate; main Glide GPU GLSL versus software JS IR is a second duplication; main GL JS versus native mirror/raster is a third. Private removes shader arithmetic duplication for admitted profiles, but GL→D3D stage/raster enum mapping (`gl-render-lowering.js:41`), D3DIM TL extraction/flat color/address semantics and Glide key/resource interpretation remain JS. They must be treated as API lowerers, not claimed API-free transport. Replacing these should be explicit slices, not moving all state blindly into an executor.
3. **Resource identity is not a global integer.** Device/context/epoch + resource generation + mip/face identity must accompany names. P:`render-programs.js` validates monotonic IDs, generation, stage and budgets; queue admission commits transactionally. `render-textures.js` owns RGBA bytes and retirement, but GL texture names, Glide virtual TMUs, D3D surfaces/subresources and target aliases remain separate. Preserve existing namespace separation even when sharing storage implementation.
4. **Consumed, completed and readable differ.** M:`d3d9-host.js:295` has separate consumption/completion promises. M:`d3d-render-worker.js:382` explicitly distinguishes freeing snapshot storage from materializing GPU surface contents. Foreign producers' legacy surface fences visit owning endpoints. A generic queue abstraction must preserve this ordering and cancellation behavior.
5. **Presentation is intentionally heterogeneous.** GPU D3D9 can publish a canvas/bitmap without READBACK; native software returns pixels. GL SwapBuffers/drawable routing and Glide front/back/gamma DAC/LFB differ from D3D swap chains. A shared PRESENT can standardize ownership/milestones, not rewrite those API semantics or add readback to every frame. Never suppress empty-looking Hype presents to improve appearance/rate.
6. **Raster conventions remain observable.** GL lower-left origin, half-pixel centers, reversed depth ranges, D3D POSITIONT, TL RHW behavior, point footprints and line endpoint rules need explicit descriptors. P native line profile is not a blanket exact WebGL diamond-exit guarantee. W-depth clear uses normalized raw16/65535, distinct from reciprocal draw encoding. Independent pixel oracles must retain these distinctions.
7. **Budgets are behavior changes.** The shared texture registry defaults to 32 MiB resident / 64 MiB transient; GL raises entry counts but retains byte limits. Old GL software Map was not equivalent. Optional native residency overflow keeps the same executor with owned snapshots; it is not renderer fallback. Q2 demonstrates one working set only. Test admission atomicity, draw-wide pinning, mapped-view exhaustion, retirement and teardown before broader capacity claims.
8. **Generated and guest shaders have separate legality.** Accepted fog fix exempts only the pair of `nativeFixedVertex` and `nativeFixedPixel` flags in P:`d3d9-backend.js:477`. Mixed guest/generated cases must still reject unsupported linkage; keep guest version/oFog validation. Exact analytical shared test pixel `[64,159,16,191]` is evidence, not a replaceable tolerance target.
9. **Transport/producer cost may dominate before raster.** Private packets still contain API envelopes, neutral sidecars and owned geometry; batching compares state and respects barriers. Main/private `gpu-backend` sharing alone says nothing about copies, compilation, upload or GPU completion costs. Program/texture caches reduce repetition but require measured hit/miss/eviction and byte counts.
